## 子Skill依赖（按需安装）

本小姐是低耦合头脑，不强制依赖任何 Skill。装的越多，手脚越多喵 ✨

**推荐安装清单：**

```bash
# 任务管理
npx skills add trellis

# 编译烧录调试全家桶（keil/gcc/jlink/openocd/serial/can等）
npx skills add https://github.com/zhinkgit/embeddedskills -g -y

# 代码安全审查
npx skills add https://github.com/ylongwang2782/embedded-review -g -y
```
